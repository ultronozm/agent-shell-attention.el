#+title: agent-shell-attention NEWS

* Unreleased

** Fix completion on older Emacs versions

The jump commands no longer depend on a completion helper missing from
Emacs 29, the minimum supported version.

* Version 0.0.3 (2026-10-08)

** Return to idle agent shells

The new command =agent-shell-attention-jump-idle= visits the most recently
visited idle shell.  Bury a shell with =M-x bury-buffer= to put it behind
the others without closing it.  With a prefix argument, the command offers
completion over idle shells in buffer order.  Shells awaiting replies or
running requests are excluded.

To bind the command alongside =agent-shell-attention-jump=:

#+begin_src emacs-lisp
(keymap-global-set "C-z b" #'agent-shell-attention-jump-idle)
#+end_src
