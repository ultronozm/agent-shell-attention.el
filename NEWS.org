#+title: agent-shell-attention NEWS

* Version 0.0.5 (2026-11-12)

** Fix parallel permission prompts

Permission prompts remain pending until all prompts in the session have
been answered.  Responding to the displayed prompt updates its label to
another outstanding prompt without changing the session's place in the
attention queue.

The minimum supported agent-shell version is now 0.52.2, which clears
answered permission IDs before emitting permission-response events.

** Keep new replies unread during previews

=agent-shell-attention-inhibit-auto-acknowledge= now also preserves
unread replies that arrive during a transient session preview.

* Version 0.0.4 (2026-11-02)

** Improve session navigation

Jump pickers and the dashboard show agent icons and session titles.
Idle navigation now counts visits through viewport buffers.

** Public interface for session browsers

Session interfaces can query unread replies with
=agent-shell-attention-unread-p= and acknowledge them with
=agent-shell-attention-acknowledge=, preserving outstanding permissions.
Bind =agent-shell-attention-inhibit-auto-acknowledge= during previews to
leave replies unread until a selection is confirmed.

** Fix completion on older Emacs versions

The jump commands no longer depend on a completion helper missing from
Emacs 29, the minimum supported version.

* Version 0.0.3 (2026-10-08)

** Return to idle agent shells

The new command =agent-shell-attention-jump-idle= visits the most recently
visited idle shell.  Bury a shell with =M-x bury-buffer= to put it behind
the others without closing it.  With a prefix argument, the command offers
completion over idle shells in buffer order.  Shells awaiting replies or
running requests are excluded.

To bind the command alongside =agent-shell-attention-jump=:

#+begin_src emacs-lisp
(keymap-global-set "C-z b" #'agent-shell-attention-jump-idle)
#+end_src
